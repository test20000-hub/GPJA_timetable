QR 기기 승인 센터

비밀번호는 그대로 유지하면서, 이 Android 앱 설치본을 관리자 승인으로 추가 보호합니다.

기기 상태

앱 상태를 확인하고 QR 승인 절차를 시작할 수 있습니다.

확인 중…

1. 관리자 키 등록

관리자 앱에서 만든 관리자 키 QR을 이 기기에서 한 번 스캔합니다. 이후 이 기기는 해당 관리자 키의 승인만 신뢰합니다.

2. 승인 요청 QR

이 기기의 1회용 승인 요청 QR을 관리자 앱에서 스캔합니다. 요청은 5분 동안만 유효합니다.

관리자 승인

관리자 기능이 활성화된 앱에서만 표시됩니다. 승인 요청 QR을 스캔한 뒤 승인 QR을 생성하여 요청 기기에 보여주세요. 관리자 기능을 켠 기기에서도 일반 시간표 앱을 그대로 사용할 수 있습니다.

3. 승인 QR 적용

관리자 앱이 만든 승인 QR을 이 기기에서 스캔하면 앱 승인 상태가 저장됩니다.

사용 순서

  1. 관리자 앱에서 관리자 키 QR을 한 번 등록합니다.
  2. 일반 앱에서 승인 요청 QR을 생성합니다.
  3. 관리자 앱이 요청 QR을 스캔하고 승인 QR을 생성합니다.
  4. 일반 앱이 승인 QR을 스캔하면 승인됩니다.
  5. 관리자 기능이 활성화된 앱은 일반 앱 기능과 관리자 기능을 동시에 사용할 수 있습니다.
  6. 사이트 비밀번호 0511은 기존대로 유지됩니다.
