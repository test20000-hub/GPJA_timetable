# 군포중앙고 시간표 Android 위젯

Android Studio에서 `android-widget` 폴더를 프로젝트로 열어 빌드합니다.

- 기본 학급: 1학년 5반
- 데이터: `https://test20000-hub.github.io/GPJA_timetable/data/timetable.json`
- 현재 교시: 09:10–10:00, 10:10–11:00, 11:10–12:00, 13:00–13:50, 14:00–14:50, 15:00–15:50, 16:00–16:50
- 쉬는 시간에는 다음 교시를 표시하도록 설계되어 있습니다.

> 참고: 현재 시간표 JSON이 비어 있으면 과목명이 표시되지 않습니다. 웹 사이트의 NEIS 갱신 workflow가 데이터를 생성한 뒤 앱을 다시 실행하면 최신 시간표를 읽습니다.
